# Apollo Chat 3.0 candidate QA — 2026-10-27

Chat 3.0 extends the existing Markdown and `apollo-ui` renderer with `apollo.rich` version 3 blocks. Legacy blocks and plain Markdown remain readable. The server strips untrusted entity metadata and accepts only bounded entity kind/name references; the authenticated same-origin lookup resolves Spotify artists/albums/songs or exact-titled Wikipedia books/movies/people/places. Provider IDs, source links, and images come from those providers, not model-authored fields. Images are checked before use and degrade to text when unavailable.

The frontend registry renders entity cards and source/image detail affordances. The contextual panel is a right-side dialog on desktop and a bottom sheet above the mobile composer area. It supports Escape, close button, focus return, and source opening without changing the chat route or scroll position. Existing galleries retain lazy loading, retry, full-size viewing, and attribution. Rich blocks persist as part of the message body; the versioned parser rejects unsupported versions and incomplete fences.

Local automated checks: 359 Python tests passed with two skips; 15 iOS configuration tests passed; production asset build, JavaScript syntax, and Git whitespace checks passed. The synthetic browser fixture demonstrated chapter headings, timeline, a provider-backed entity card, desktop side panel, mobile sheet, Escape close, and missing-image monogram fallback. Browser captures are `/private/tmp/apollo-chat3-desktop.png` and `/private/tmp/apollo-chat3-mobile-panel.png` on the development machine.
