Production release procedure: [prepared production releases](../architecture/production-deployment.md). A new candidate requires a commit and exact SHA, a matching server-side readiness manifest, verified private backups, database migration rehearsal, old-backend compatibility rehearsal, model fingerprint and rollback script, then the existing GitHub Actions → SSH → systemd workflow. The 2026-10-21 backup and manifest cannot authorize a different SHA. No new production deployment or production data migration was performed in this audit. Do not push to `main` or trigger the workflow until the new gate is prepared and verified on the deployment host.
