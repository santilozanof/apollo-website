# FL Studio files in Apollo Studio

Studio already stores projects, tracks, BPM, key, notes, audio versions, artwork, reference links and release status. For an FL Studio project, open its Apollo project, choose **World → Add Media**, and upload the `.flp` file. Apollo stores a private copy in that project's media library and labels it **FL STUDIO**. Selecting it downloads the original file so macOS can open the local copy in FL Studio. This is a file handoff; Apollo does not edit the FL Studio project or control the FL Studio app.

Keep related mix exports in the track's **Versions** section, and use track BPM/key and project notes for production context. Web references must use HTTP or HTTPS; browser `file://` links and executable URL schemes are rejected. Existing Studio records and files are not migrated or rewritten by this feature.
